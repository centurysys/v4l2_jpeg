# v4l2_jpeg

## 概要

`v4l2_jpeg` は、V4L2 M2M を利用したハードウェア JPEG エンコーダーの Nim ライブラリです。

Texas Instruments AM67A（e5010 JPEG エンコーダ）向けに最適化されており、ソフトウェアエンコーダ（libjpeg-turboなど）と比較して非常に高速に動作します。

## パフォーマンス

AM67A（Cortex-A53環境）での実測値：

- 解像度: 1920x1080（Full HD）
- 品質: 90
- エンコード時間: **約 7.5 ms / フレーム**

CPUベースのJPEGエンコードと比較して大幅に高速です。

## 特徴

- V4L2 M2M によるハードウェアJPEGエンコード
- NV12 / NM12 フォーマット対応
- 低レイテンシ
- リアルタイム処理向け
- Nim向けAPI

## 注意

- **ハードウェア依存**です
- 現在確認済み環境:
  - TI AM67A（e5010 JPEG encoder）
- V4L2ドライバの対応が必要です

## 推奨パイプライン

```
NV12入力 -> v4l2_jpeg -> JPEG出力
```

最高性能を得るためには、RGB/RGBAへの変換を避け、YUV系フォーマットのまま処理することを推奨します。

# v4l2_jpeg

Linux向け V4L2 M2M JPEGエンコーダライブラリ（Nim）

このライブラリは、V4L2 を通じてハードウェアJPEGエンコーダ （例: AM67A の
E5010）を簡単に利用するための高レベルAPIを提供します。

------------------------------------------------------------------------

## 特徴

-   V4L2 JPEGエンコーダの自動検出
-   NV12 / NM12 入力対応
-   ハードウェアJPEGエンコード
-   JPEG品質（quality）の制御
-   シンプルで再利用しやすいAPI
-   ゼロコピーを意識した設計

------------------------------------------------------------------------

## 動作条件

-   V4L2 M2M 対応 Linux
-   JPEGエンコーダデバイス（例: `/dev/videoX`）
-   対応フォーマット:
    -   入力: NV12 / NM12
    -   出力: JPEG

------------------------------------------------------------------------

## インストール

nimble 依存として追加、またはリポジトリを直接配置してください。

------------------------------------------------------------------------

## 簡単な使用例

``` nim
import v4l2_jpeg

let enc = ?JpegEncoder.open(1920, 1080)

let jpeg = ?enc.encode(frame)
echo jpeg.len
```

------------------------------------------------------------------------

## デバイス選択

デバイス未指定時は自動検出されます:

``` nim
let enc = ?JpegEncoder.open(1920, 1080)
```

明示指定する場合:

``` nim
let enc = ?JpegEncoder.open(1920, 1080, device="/dev/video0")
```

------------------------------------------------------------------------

## quality（画質）制御

open時にデフォルト設定:

``` nim
let enc = ?JpegEncoder.open(1920, 1080, quality=90)
```

encodeごとに上書き:

``` nim
let jpeg = ?enc.encode(frame, quality=70)
```

------------------------------------------------------------------------

## 性能

参考値（AM67A + E5010）:

-   1920x1080 NV12 → JPEG: 約 7〜8 ms / フレーム

------------------------------------------------------------------------

## 設計方針

-   GStreamerに依存せず V4L2 を直接使用
-   低レベルbindingと高レベルAPIを分離
-   libyuv との連携を前提とした設計
